# 修复记录

## 修复的问题

### 1. 文件上传确认按钮问题
**问题**: 选择文件后确认上传按钮仍然禁用  
**修复**: 
- 在 `showFileInfo()` 函数中显式启用按钮
- 添加调试日志
- 打开上传弹窗时重置状态

### 2. 网络搜索参数关联
**问题**: 网络搜索选项没有正确关联到 `is_web_search` 参数  
**修复**:
- 使用 `webSearchToggle.checked` 获取复选框状态
- 添加到请求数据中
- 添加调试日志输出

## 调试方法

打开浏览器控制台（F12），可以看到：
- 文件选择时的日志：`Files selected: X Button disabled: false`
- 发送请求时的日志：`Sending request: {question: "...", is_web_search: true/false, ...}`

## 使用步骤

### 上传文件
1. 点击 "📁 上传文档"
2. 点击 "📁 选择文件" 区域
3. 选择文件
4. 查看已选择的文件列表
5. **确认上传按钮应该自动启用**
6. 点击 "确认上传"

### 使用网络搜索
1. 勾选 "网络搜索" 选项
2. 输入问题
3. 发送消息
4. 查看控制台日志，确认 `is_web_search: true`
