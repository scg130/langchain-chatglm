# 前端使用说明

## 功能特性

### 1. 聊天功能
- 实时对话界面
- 支持历史对话
- 输入框自动调整高度
- 回车发送消息

### 2. 文件上传
- 支持 .txt, .pdf, .docx, .md 格式
- 批量上传多个文件
- 上传进度显示
- 自动更新知识库列表

### 3. 网络搜索
- 开启/关闭网络搜索
- 获取最新信息

### 4. 知识库选择
- 下拉选择不同的知识库
- 显示每个知识库的文件数量

## 启动方式

1. 启动后端服务：
```bash
python run.py
```

2. 打开浏览器访问：
```
http://127.0.0.1:8800
```

## API端点

- `GET /` - 前端页面
- `POST /api/v1/ask` - 提问接口
- `POST /api/v1/upload` - 文件上传
- `GET /api/v1/knowledge-bases` - 获取知识库列表

## 使用流程

1. **上传文档**：点击"上传文档"按钮，选择文件
2. **提问**：在输入框输入问题
3. **选择知识库**：从下拉菜单选择使用的知识库
4. **开启搜索**：勾选"网络搜索"获取最新信息
5. **清空对话**：点击"清空对话"开始新会话
